# 🎨 Tekenprogramma

Een simpel tekenprogramma gebouwd met Vue 3 en Vuetify.

## Features

- ✏️ Pen tool
- 🧽 Gum
- 🪣 Vulemmertje (flood fill)
- 🎨 Kleurkiezer
- 📏 Instelbare penseeldikte
- ↩️ Undo / Redo
- 🗑️ Canvas wissen
- 💾 Opslaan als PNG

## Gebruik

Open `index.html` in je browser, of bekijk de live versie.

## Tech

- [Vue 3](https://vuejs.org/)
- [Vuetify 3](https://vuetifyjs.com/)
- HTML5 Canvas
